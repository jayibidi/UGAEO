# 平台分层与标签（v2.4.0）

分两个维度打标签，互不替代：

- **内容形态**：图文类 / 资讯类 —— 只作为账号卡片上的标签，不参与分组
- **发布能力**：可直发 / 仅草稿 —— 决定账号页的层级，可直发在第一层

层级不是手写死的，由适配器 `capabilities` 是否包含 `publish` 推导；分类表在
`packages/core/src/adapters/platform-profiles.ts`。

当前共 34 个平台：**可直发 16 个 / 仅草稿 18 个**（另有「Markdown 压缩包」是本地导出工具，不参与分层）。

## 页面驱动（page-publish）说明

以下平台没有开放 API，或有签名 / 风控校验，走「打开创作者后台 → 页面内填内容 → 触发发布」：

头条号、小红书、网易号、企鹅号、36氪、虎嗅、界面新闻、简书、什么值得买、
顺企网、八方资源网、黄页88、IT之家、InfoQ、快懂百科、百度知道

行为约定：

1. 会打开（或复用）对应平台的编辑器 / 投稿页标签页
2. **草稿模式下也会开这个标签页** —— 内容必须填进页面才能保存
3. 结果分三级，绝不假装成功：
   - `已发布`：检测到成功提示或页面跳转
   - `已提交`：已点发布但页面没给明确反馈，需到平台确认
   - `已填入`：内容填好了但没找到发布按钮，需手动点

平台改版会导致选择器失效。这种情况结果是「已填入」或「未找到编辑器」，
不会误报成功；把结果页的提示发回来即可按新结构补选择器。
